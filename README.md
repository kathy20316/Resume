# 🚀 Personal Portfolio & Online Resume

Welcome to the repository for my personal website and online resume! This project serves as an interactive hub to showcase my professional experience, featured software engineering projects, technical stack, and education.

[**🌐 View Live Site**](https://kathy20316.github.io/Resume/) 

---

## 🛠️ Built With

This site is designed to be lightweight, responsive, fast-loading, and easy to maintain.

* **Frontend:** [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)
* **Styling:** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
* **Deployment & Hosting:** [GitHub Pages](https://pages.github.com/)

## 💻 Local Development Setup

To run this project locally on your machine, follow these steps:

**Clone the repository:**
* Open your IDE/ Text\
* Open Terminal\
* In Terminal:\
   * mkdir online-resume
   * git clone https://github.com/kathy20316/Resume.git
   * cd online-resume
